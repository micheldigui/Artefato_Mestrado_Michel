## Resumo
Artigo fundamental de definição e sistematização da **Ciência de Dados (CD)** como disciplina científica emergente. Os autores — pesquisadores da Xi'an Jiaotong University (China) — traçam a epistemologia da área: como a explosão do *Big Data* gerou a necessidade de um novo campo que integrasse Matemática, Estatística, Ciência da Computação e Inteligência Artificial para extrair valor de dados complexos e heterogêneos.

## Principais Tópicos
- **Definição Formal de Data Science:** Disciplina que usa teorias e métodos de diversas áreas para analisar Big Data e transformá-lo em produtividade real — a base epistemológica que justifica o seu projeto de pesquisa.
- **Metodologias:** Algoritmos *TPC* (Theoretically Provable Correctness), interpretáveis, generalizáveis, paralelos e escaláveis — alinhados exatamente com os critérios que guiam a escolha de algoritmos de árvore (Random Forest, ExtraTrees) na sua dissertação.
- **Mundo Ternário:** O conceito de interação entre o espaço humano, físico e informacional — framework interessante para situar o RU como sistema produtivo que integra dados físicos (clima, presença) e digitais (reservas).

## Pertinência para o Projeto
**Alta (Fundamentação Epistemológica).** Este é o artigo base para sustentar, no **Referencial Teórico**, a legitimidade da Ciência de Dados como método de pesquisa aplicado a sistemas produtivos. Valida o uso de dados heterogêneos (histórico + clima + cardápio) como insumo para geração de conhecimento científico.
