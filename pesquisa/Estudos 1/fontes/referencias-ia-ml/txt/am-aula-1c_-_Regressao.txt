Aprendizado Supervisionado - Regressão
➔ Utilizada para prever valores numéricos contínuos a partir da relação entre
variáveis de entrada e uma variável de saída
Regressão Linear
➔ É uma técnica estatística e de aprendizado de máquina que modela a relação
entre uma variável dependente e uma ou mais variáveis independentes por
meio de uma reta (ou hiperplano), permitindo explicar e prever valores da
variável de interesse.
◆ uma variável desconhecida, ou dependente, muitas vezes chamada de variável de resultado
◆ uma ou mais variáveis independentes, frequentemente chamados de preditores, covariáveis,
recursos, ou features
Regressão Linear - Exemplo
➔ Imagine que você quer prever o preço de uma casa baseado apenas no seu
tamanho em metros quadrados. A fórmula básica é a equação da reta:
◆
Y = a + b × X
◆ Onde:
● a → Valor de partida
● b → Quanto o preço aumenta a cada m2 a mais na área do imóvel
● Y → O preço previsto do imóvel
● X → A área do imóvel em m2

import matplotlib.pyplot as plt
import numpy as np
# Dados observados (lotes)
X_dados = np.array([480, 510, 520, 850, 960, 1200, 1400, 1650, 1700, 1920, 2350])
Y_dados = np.array([98, 110, 200, 210, 280, 265, 300, 287, 325, 300, 290])
# -----------------------------------------------------------------
# Procura pelos melhores parâmetros utilizando o Mean Squared Error
# -----------------------------------------------------------------
menor_mse = np.inf
print("Valor Inicial para MSE:", menor_mse)
melhor_a = 0
melhor_b = 0
# Inclinação aproximada
b_estimado = (Y_dados.max() - Y_dados.min()) / (X_dados.max() - X_dados.min())
# Intercepto aproximado
a_estimado = np.mean(Y_dados - b_estimado * X_dados)
print("Estimado para a:", a_estimado)
print("Estimado para b:", b_estimado)

Regressão Linear Múltipla
➔ A Regressão Linear Múltipla é um algoritmo de aprendizado supervisionado
utilizado para prever o valor de uma variável dependente a partir de duas ou
mais variáveis independentes
➔ Enquanto a regressão linear simples utiliza apenas uma variável de entrada,
a regressão linear múltipla utiliza várias variáveis ao mesmo tempo, tornando
a previsão geralmente mais precisa
Regressão Linear Múltipla
➔ Imagine que desejamos prever a expectativa de vida (Life Expectancy) de um país
Sabemos que ela depende de diversos fatores, por exemplo:
◆ Mortalidade de adultos (Adult Mortality)
◆ Consumo de álcool (Alcohol)
◆ Magreza entre 1 e 19 anos (Thinness 1–19 years)
◆ Escolaridade (Schooling)
➔ Em vez de utilizar apenas uma dessas informações, utilizamos todas simultaneamente
